Black & white pictures of whatever is playing.

A 1-bit audio visualizer for your desktop. It listens to Spotify, YouTube, a game, anything, and draws the music as it happens. Bass, vocals and hats each get their own shape, quiet songs stay sparse, loud ones fill the screen, and every song gets a new layout.

Examples, drawn from real music

What it does

Seven looks, fusable

Spots, Shapes, Adaptive, Weather, Bursts, Ink waves, Field. Use one or fuse several, and switch any element off.

Mix it yourself

A slider each for bass, low mids, vocals, snare and hats, plus Intensity from subtle to jarring.

Pixels or characters

Dithered 1–4 bit pixels, or ASCII, symbols, shapes and binary, picked by brightness.

One app or everything

On Windows, follow all system audio or just one app, so notifications don't join in.

Presets you can share

Save a look, then copy a short code. Whoever pastes it gets exactly the same picture.

Randomize

Press Space to shuffle everything until something clicks.

Install & run

Windows

Windows 10 or 11 · about 30 MB · no installer

  1. Download AudioVisualizer-windows.exe.
  2. Double-click it. It's a single file, so there's nothing to install. Put it anywhere you like.
  3. If Windows shows "Windows protected your PC", click More info then Run anyway. This appears because the app isn't code-signed.
  4. Play some music. The visualizer follows whatever you can hear, with no setup.
  5. Press Tab for settings, F for fullscreen. In Audio, pick a single app (like Spotify) to follow.

Mac

macOS on Apple silicon (M1 and newer) · for Intel Macs, run it from source below

  1. Download AudioVisualizer-mac.zip and double-click it to unzip. Drag AudioVisualizer into Applications.
  2. The first time, right-click the app → Open → Open. The app isn't notarized, so macOS asks once. On macOS 15 or newer, if there's no Open button: open it once, then go to System Settings → Privacy & Security and click Open Anyway.
  3. Click Allow when it asks for the microphone. That's how it hears the music.
  4. Press Tab for settings, F for fullscreen.
Make it react to music playing on the Mac itself (not the room)

macOS doesn't let apps listen to system audio directly, so by default the visualizer hears your microphone. To feed it the Mac's own sound:

  1. Install the free BlackHole 2ch audio driver.
  2. Open Audio MIDI Setup, click + → Create Multi-Output Device, and tick your speakers and BlackHole 2ch.
  3. In System Settings → Sound, set Output to the Multi-Output Device and Input to BlackHole 2ch.
  4. Restart the visualizer. You'll hear the music as normal, and it sees it too.

Run from source instead (any Mac, Windows or Linux with Python 3.10+)

Download the code from GitHub (Code → Download ZIP), unzip it, then double-click Run-Windows.bat on Windows or Run-Mac.command on a Mac. The first run sets itself up (a minute or so). Or from a terminal:

git clone https://github.com/karunalk97-sketch/visualizer.git
cd visualizer
python -m pip install -e .
python -m visualizer.main

Useful flags: --fullscreen, --demo (a built-in test tone), --app spotify (Windows: follow one app), --preset "Preset 2" or --preset AVP1.… (start with a saved look or a share code).
